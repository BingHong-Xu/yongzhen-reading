# 苗栗縣頭份市永貞國民小學 114學年度「深耕閱讀」推動計畫成果展示網

> **書香「永」恆，「貞」惜閱讀**  
> 閱讀推動教師：徐秉鴻老師（STEM Teacher Bing）  
> 成果全典藏：78 個主題專欄、672 篇推動篇章、517+ 份高畫質本機圖影檔案

## 🌟 核心特色
- **114學年度深耕閱讀專區**：完整收錄 114-1 及 114-2 閱讀推動內容、官方計畫原件 PDF、主題書展獲獎成果。
- **多元閱讀推動專案**：
  - 身教式持續安靜閱讀（MSSR）與《咻！「苗」準世界》雙語早修廣播劇
  - 「明日說書人」繪本有聲導讀與聊書學習站
  - 「子。竹。嚐。肉」永貞校本跨領域特色課程
  - 圖書館 1.0～4.0 改建美學藍圖意象
- **三種靈活部署與存取模式**：
  1. **本機離線免安裝**：雙擊 `index.html` 或桌面捷徑即可 100% 離線預覽。
  2. **輕量伺服器模式**：雙擊 `start_preview.bat` 啟動本地 http 伺服器 (`http://localhost:8080`)。
  3. **Google Sites / iframe 內嵌專用頁**：`google_sites_embed.html` 及 `google_sites_all_in_one.html`，具備安全儲存與沙盒相容機制。
